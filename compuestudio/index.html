LocalStorage en JavaScript

Guía práctica para aprender a almacenar, consultar, actualizar y eliminar información utilizando HTML, JavaScript y el DOM.

1. ¿Qué es LocalStorage?

LocalStorage es una funcionalidad del navegador que permite almacenar información de manera local. Los datos permanecen guardados incluso cuando cerramos o actualizamos la página.

1.1. ¿Para qué sirve?

  • Guardar información de usuarios.
  • Almacenar productos de un inventario.
  • Conservar registros de formularios.
  • Guardar preferencias del usuario.
  • Crear aplicaciones sencillas sin utilizar bases de datos.
Importante: LocalStorage almacena información en el navegador. No necesita una conexión a una base de datos ni a un servidor.

1.2. Variable tradicional vs LocalStorage

Variable JavaScript LocalStorage
Guarda información temporalmente en memoria. Conserva información en el navegador.
Normalmente pierde su valor al recargar la página. Mantiene los datos después de recargar.
Se utiliza directamente en JavaScript. Se utiliza mediante sus métodos.
LocalStorage no es una base de datos segura. No debemos guardar contraseñas, tokens ni información sensible.

2. ¿Dónde se guarda la información?

La información se almacena dentro del navegador que estamos utilizando.

2.1. ¿Cómo consultar los datos guardados?

  1. Abre el proyecto en Google Chrome o Edge.
  2. Presiona la tecla F12.
  3. Selecciona la pestaña Application (Aplicación).
  4. Busca Storage y selecciona Local Storage.
  5. Selecciona el origen de tu página.
  6. Observa las columnas Key y Value.
También puedes acceder a las herramientas de desarrollador haciendo clic derecho sobre la página y seleccionando Inspeccionar.

Cada registro se almacena mediante una clave y un valor. Por ejemplo:

Key Value
nombre Carlos
ciudad Medellín

3. Ejercicios independientes con LocalStorage

En esta guía construirás cuatro ejercicios pequeños para guardar y administrar una lista de nombres. Cada operación tiene su propio formulario y su propio bloque de código.

3.1. Crear la carpeta del proyecto

Crea la carpeta localstorage_explicacion y dentro agrega estos dos archivos:

localstorage_explicacion/
├── index.html
└── app.js

3.2. Crear el formulario en index.html

Escribe el HTML siguiente en localstorage_explicacion/index.html. Cada ejercicio está separado y cada campo de entrada está dentro de su sección.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>
    <section>
        <h2>Ejercicio 1. Guardar un nombre</h2>
        <form action="">
            <label for="">Nombre:</label>
            <input type="text" id="nombreGuardar">
            <button type="button" onclick="guardarNombre()">Guardar Nombre</button>
        </form>
        <p id="resultadoGuardar"></p>
    </section>

    <script src="app.js"></script>
</body>
</html>

3.3. Ejercicio 1: guardar un campo

El botón llama a guardarNombre(). Escribe esta función en app.js: agrega cada nombre a una lista JSON almacenada bajo la clave Nombre.

function guardarNombre(){

    let nombre =document.getElementById("nombreGuardar").value.trim();

    if(nombre===""){
        alert("Por favor ingrese el nombre");
        return;
    }else{
        let listaNombres =JSON.parse(localStorage.getItem("Nombre")) ||[];
        listaNombres.push(nombre);

        localStorage.setItem("Nombre", JSON.stringify(listaNombres));

        document.getElementById("nombreGuardar").value ="";
        document.getElementById("resultadoGuardar").innerText=`Nombre guardado ${nombre}`;

    }

}

Como el botón es de tipo button, no envía el formulario. Los nombres se guardan como una lista JSON en LocalStorage.

3.4. Ejercicio 2: mostrar los nombres guardados

Agrega esta sección a index.html, debajo del ejercicio 1. No necesita un campo de entrada: el botón llama a la función que mostrará los nombres guardados.

    <section>
        <h2>Ejercicio 2: Mostrar los nombres guardados</h2>
        <form action="">
            <button type="button" onclick="mostrarNombre()">Mostrar Nombres</button>
        </form>

        <p id="resultadoMostrar"></p>
    </section>

Ahora agrega en app.js la función que recupera la lista guardada en la clave Nombre y muestra cada nombre como un elemento de lista.

function mostrarNombre() {

    let listaNombres = JSON.parse(localStorage.getItem("Nombre")) || [];

    let resultado = document.getElementById("resultadoMostrar");

    if (listaNombres.length === 0) {
        resultado.innerHTML = "<li>No hay nombres guardados</li>";
        return;
    }

    resultado.innerHTML = listaNombres.map(n => `<li>${n}</li>`).join("");

}

La función genera un elemento de lista para cada nombre guardado.

3.5. Ejercicio 3: editar un nombre guardado

Agrega esta sección en index.html. Escribe la posición del nombre que deseas editar (según el orden en que aparece al mostrar los nombres) y el nuevo nombre que deseas guardar.

    <section>
        <h2>Ejercicio 3: Editar un nombre</h2>

        <label>Posición del nombre:</label>
        <input type="number" id="posicionEditar">

        <label>Nuevo nombre:</label>
        <input type="text" id="nuevoNombre">

        <button type="button" onclick="editarNombre()">
            Editar Nombre
        </button>

        <p id="resultadoEditar"></p>
    </section>

En app.js, valida la posición y el nuevo nombre antes de reemplazar solamente el elemento seleccionado.

function editarNombre(){

    let posicion = document.getElementById("posicionEditar").value;

    let nuevoNombre = document.getElementById("nuevoNombre").value.trim();

    let listaNombres = JSON.parse(localStorage.getItem("Nombre")) || [];

    if(posicion === "" || nuevoNombre === ""){
        alert("Complete todos los campos");
        return;
    }

    posicion = Number(posicion) - 1;

    if(posicion < 0 || posicion >= listaNombres.length){
        alert("La posición no existe");
        return;
    }

    listaNombres[posicion] = nuevoNombre;

    localStorage.setItem("Nombre", JSON.stringify(listaNombres));

    document.getElementById("resultadoEditar").innerText =
        "Nombre actualizado correctamente";

    document.getElementById("nuevoNombre").value = "";
}

3.6. Ejercicio 4: eliminar todos los nombres guardados

Agrega esta sección en index.html. El botón llama a la función que elimina la lista completa de nombres.

    <section>
        <h2>Ejercicio 4: Eliminar todos los nombres guardados.</h2>
        <form action="">
            <button type="button" onclick="eliminarNombre()">Eliminar todos.</button>
        </form>
        <p id=""></p>
    </section>

En app.js, define eliminarNombre() para borrar la clave Nombre, que contiene la lista completa.

function eliminarNombre() {

    localStorage.removeItem("Nombre");

    document.getElementById("resultadoEliminar").innerText =
        "Se eliminaron todos los nombres";

}

3.7. Probar con un objeto

LocalStorage solo almacena cadenas de texto. Si intentas guardar un objeto, lo convertirá a [object Object]. Para guardar un objeto, primero debes convertirlo a JSON con JSON.stringify(). Para leerlo, utiliza JSON.parse().

3.7.1. Formulario para registrar una mascota (Objeto)

    <section>
        <h2>Guardar una mascota</h2>
        <form action="">
            <label for="mascota">Mascota:</label>
            <input type="text" id="mascota">

            <label for="raza">Raza:</label>
            <input type="text" id="raza">

            <label for="edad">Edad:</label>
            <input type="number" id="edad" min="0">

            <button type="button" onclick="guardarMascota()">Guardar mascota</button>
        </form>
        <p id="resultadoMascota"></p>
    </section>

En app.js, crea la función que reúne los campos en un objeto y lo convierte a JSON antes de guardarlo.

function guardarMascota() {
    const mascota = {
        nombre: document.getElementById("mascota").value.trim(),
        raza: document.getElementById("raza").value.trim(),
        edad: Number(document.getElementById("edad").value)
    };

    localStorage.setItem("mascota", JSON.stringify(mascota));
    document.getElementById("resultadoMascota").textContent =
        "Mascota guardada correctamente.";
}
