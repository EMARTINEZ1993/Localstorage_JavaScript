LocalStorage en JavaScript

Guía práctica para aprender a almacenar, consultar, actualizar y eliminar información utilizando HTML, JavaScript y el DOM.

1. ¿Qué es LocalStorage?

LocalStorage es una funcionalidad del navegador que permite almacenar información de manera local. Los datos permanecen guardados incluso cuando cerramos o actualizamos la página.

¿Para qué sirve?

  • Guardar información de usuarios.
  • Almacenar productos de un inventario.
  • Conservar registros de formularios.
  • Guardar preferencias del usuario.
  • Crear aplicaciones sencillas sin utilizar bases de datos.
Importante: LocalStorage almacena información en el navegador. No necesita una conexión a una base de datos ni a un servidor.

Variable tradicional vs LocalStorage

Variable JavaScript LocalStorage
Guarda información temporalmente en memoria. Conserva información en el navegador.
Normalmente pierde su valor al recargar la página. Mantiene los datos después de recargar.
Se utiliza directamente en JavaScript. Se utiliza mediante sus métodos.
LocalStorage no es una base de datos segura. No debemos guardar contraseñas, tokens ni información sensible.

2. ¿Dónde se guarda la información?

La información se almacena dentro del navegador que estamos utilizando.

¿Cómo consultar los datos guardados?

  1. Abre el proyecto en Google Chrome o Edge.
  2. Presiona la tecla F12.
  3. Selecciona la pestaña Application (Aplicación).
  4. Busca Storage y selecciona Local Storage.
  5. Selecciona el origen de tu página.
  6. Observa las columnas Key y Value.
También puedes acceder a las herramientas de desarrollador haciendo clic derecho sobre la página y seleccionando Inspeccionar.

Cada registro se almacena mediante una clave y un valor. Por ejemplo:

Key Value
nombre Carlos
ciudad Medellín

3. Ejercicios independientes con LocalStorage

En esta guía construirás cuatro ejercicios pequeños para trabajar con un solo dato de texto. Cada operación tiene su propio formulario y su propio bloque de código.

3.1. Crear la carpeta del proyecto

Crea la carpeta localstorage_explicacion y dentro agrega estos dos archivos:

localstorage_explicacion/
├── index.html
└── app.js

3.2. Crear los formularios en index.html

Escribe el HTML siguiente en localstorage_explicacion/index.html. Cada ejercicio está separado y cada campo de entrada está dentro de su formulario.

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Ejercicios independientes de LocalStorage</title>
</head>
<body>
    <h1>Ejercicios de LocalStorage</h1>

    <section>
        <h2>Ejercicio 1. Guardar un nombre</h2>
        <form id="formGuardar">
            <label for="nombreGuardar">Nombre:</label>
            <input id="nombreGuardar" type="text">
            <button type="submit">Guardar nombre</button>
        </form>
        <p id="resultadoGuardar"></p>
    </section>

    <script src="app.js"></script>
</body>
</html>

3.3. Preparar app.js

En localstorage_explicacion/app.js, define una clave y conecta cada formulario, campo y mensaje con JavaScript.

const claveNombre = "localstorage_explicacion_nombre";

const formGuardar = document.getElementById("formGuardar");
const nombreGuardar = document.getElementById("nombreGuardar");
const resultadoGuardar = document.getElementById("resultadoGuardar");

La misma clave se utiliza en los cuatro ejercicios para que consultar, editar y eliminar operen sobre el dato guardado.

3.4. Ejercicio 1: guardar un campo

Conecta el primer formulario al evento submit. setItem() guarda el texto usando la clave definida anteriormente.

formGuardar.addEventListener("submit", function (evento) {
    evento.preventDefault();

    const nombre = nombreGuardar.value.trim();
    if (nombre === "") {
        resultadoGuardar.textContent = "Escribe un nombre antes de guardarlo.";
        return;
    }

    localStorage.setItem(claveNombre, nombre);
    resultadoGuardar.textContent = "Nombre guardado correctamente.";
    formGuardar.reset();
});

preventDefault() evita que el formulario recargue la página. trim() quita espacios al inicio y al final.

3.5. Ejercicio 2: mostrar el campo guardado

Agrega este segundo formulario a index.html. No necesita un campo de entrada: solo contiene el botón que solicitará el nombre guardado.

    <section>
        <h2>Ejercicio 2. Mostrar el nombre guardado</h2>
        <form id="formMostrar">
            <button type="submit">Mostrar nombre</button>
        </form>
        <p id="resultadoMostrar"></p>
    </section>

Ahora agrega en app.js el evento que consulta la clave con getItem() y coloca el resultado en el párrafo.

const formMostrar = document.getElementById("formMostrar");
const resultadoMostrar = document.getElementById("resultadoMostrar");

formMostrar.addEventListener("submit", function (evento) {
    evento.preventDefault();

    const nombreGuardado = localStorage.getItem(claveNombre);
    resultadoMostrar.textContent = nombreGuardado === null
        ? "No hay un nombre guardado."
        : "Nombre guardado: " + nombreGuardado;
});

Si la clave no existe, getItem() devuelve null; por eso se comprueba antes de mostrar el resultado.

3.6. Ejercicio 3: editar el campo guardado

Agrega a index.html un tercer formulario con un campo para escribir el nuevo nombre. Mantén el campo dentro del formulario.

    <section>
        <h2>Ejercicio 3. Editar el nombre guardado</h2>
        <form id="formEditar">
            <label for="nombreEditar">Nuevo nombre:</label>
            <input id="nombreEditar" type="text">
            <button type="submit">Actualizar nombre</button>
        </form>
        <p id="resultadoEditar"></p>
    </section>

Después conecta el envío en app.js. Guardar con la misma clave actualiza el valor anterior; no se necesita un método update().

const formEditar = document.getElementById("formEditar");
const nombreEditar = document.getElementById("nombreEditar");
const resultadoEditar = document.getElementById("resultadoEditar");

formEditar.addEventListener("submit", function (evento) {
    evento.preventDefault();

    const nuevoNombre = nombreEditar.value.trim();
    if (nuevoNombre === "") {
        resultadoEditar.textContent = "Escribe el nuevo nombre.";
        return;
    }

    localStorage.setItem(claveNombre, nuevoNombre);
    resultadoEditar.textContent = "Nombre actualizado correctamente.";
    formEditar.reset();
});

3.7. Ejercicio 4: eliminar el campo guardado

Agrega el cuarto formulario en index.html. No necesita un campo de entrada; solo tendrá el botón para eliminar la clave del ejercicio.

    <section>
        <h2>Ejercicio 4. Eliminar el nombre guardado</h2>
        <form id="formEliminar">
            <button type="submit">Eliminar nombre</button>
        </form>
        <p id="resultadoEliminar"></p>
    </section>

Por último, conecta el formulario en app.js. removeItem() elimina únicamente la clave usada en estos ejercicios.

const formEliminar = document.getElementById("formEliminar");
const resultadoEliminar = document.getElementById("resultadoEliminar");

formEliminar.addEventListener("submit", function (evento) {
    evento.preventDefault();

    localStorage.removeItem(claveNombre);
    resultadoEliminar.textContent = "Nombre eliminado.";
});

3.8. Probar con un objeto

LocalStorage solo almacena cadenas de texto. Si intentas guardar un objeto, lo convertirá a [object Object]. Para guardar un objeto, primero debes convertirlo a JSON con JSON.stringify(). Para leerlo, utiliza JSON.parse().

Formulario para registrar una mascota (Objeto)

    <form id="formMascota">
        <label for="mascota">Mascota:</label>
        <input type="text" id="mascota" name="mascota">

        <label for="raza">Raza:</label>
        <input type="text" id="raza" name="raza">

        <label for="edad">Edad:</label>
        <input type="number" id="edad" name="edad" min="0">

        <button type="submit">Guardar mascota</button>
    </form>
const formMascota = document.getElementById("formMascota");

formMascota.addEventListener("submit", (event) => {
    event.preventDefault();

    const mascota = {
        nombre: document.getElementById("mascota").value,
        raza: document.getElementById("raza").value,
        edad: Number(document.getElementById("edad").value)
    };

    localStorage.setItem("mascota", JSON.stringify(mascota));
});
