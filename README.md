# LocalStorage en JavaScript

Guía académica en español para aprender a guardar, consultar, actualizar y eliminar datos con HTML, JavaScript y LocalStorage.

## Contenido

- `index.html`: conceptos básicos y ejercicios independientes paso a paso.
- `proyecto.html`: guía para construir un CRUD de estudiantes.
- `solucion/index.html`: página ejecutable con ejercicios de texto y un ejemplo de almacenamiento de objetos.
- `css/style.css`: estilos de las guías.
- `solucion/js/app.js`: lógica de los ejercicios ejecutables.

## Cómo usarlo

1. Descarga o clona este repositorio.
2. Abre `index.html` en el navegador para comenzar con la guía.
3. Continúa con `proyecto.html` para seguir la construcción del CRUD.
4. Abre `solucion/index.html` para probar los ejercicios funcionales.

Se recomienda abrir las páginas con una extensión de servidor local, como Live Server de VS Code. Los datos se guardan en LocalStorage del navegador y del origen utilizado; no se envían a un servidor.
